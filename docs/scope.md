# 研究范围

Palimpsest 证明固定来源、共享均匀格承诺矩阵下的高 arity 关系累积。模型为交互式、单会话、经典完整重放和有界深度；提取输出全部合法来源及与原中心后缀匹配的零 genesis 历史。终端采用实际公开短 opening 检查，计算假设是明确矩阵分布与范数下的 Module-SIS。

原型实现 R54 融合提取的局部接口。R18 无放回两点路线已有完整替代定理和有限算术核验，尚未实现完整提取器。两者的递推系数是费用上界，不是实测加速比；完整真实参数递归系统不在本仓库的实现范围。

默认 m806 scalar-bit 来源可由公开承诺直接恢复：A 的系数矩阵为均匀的 2048×806 标量矩阵，满列秩失败概率小于 $q^{-1243}/(1-1/q)$。满秩时左逆恢复、全像检查和来源关系检查构成直接控制路线，无附加 opening 或 folding 消息。因此该实例展示算术编译、编码和参数账本，不用来论证复杂来源提取的必要性。公开恢复不替代协议接受事件到有效历史的归约。详见 [证明与成本](../paper/research-notes.md#appendix-public-recovery)。

当前结论不包括零知识、Fiat–Shamir/QROM、并发多会话、自适应新增来源、任意深度或离线简洁历史证书。在线 verifier 仍持有或访问全部冻结来源输入；完整通信计入来源、F/K、挑战和终端。消息含显式二次交叉项。

统计错误、q 的编码位宽和计算安全分别报告。已有 generic-SIS 攻击模型诊断不构成有限时间优势上界，也不构成 128-bit 安全认证。源码测试检查局部公式和接口；一般安全结论由 [完整研究笔记](../paper/research-notes.md) 中的证明支撑。
